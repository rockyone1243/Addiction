⚙️ 전시장 상시 상영 설정

📖 GitHub Pages 상시 상영관 A to Z 완벽 구축 매뉴얼

1 깃허브(GitHub) 저장소(Repository) 만들기

  1. GitHub.com 로그인 후 우측 상단 [+] → [New repository] 클릭
  2. Repository name에 원하는 주소 입력 (예: grad-exhibition-2026)
  3. Public(공개) 선택 (무료 GitHub Pages는 Public 저장소에서 지원됩니다)
  4. Add a README file 체크 후 [Create repository] 클릭

2 index.html 파일 업로드하기

현재 보고 계시는 이 웹페이지 코드 전체를 index.html 이라는 이름으로 저장소 루트에 올립니다. (저장소 페이지에서 [Add file] → [Upload files] 사용)

3 GitHub Pages 24시간 상시 호스팅 활성화

  1. 저장소 상단 메뉴의 [Settings] 탭 클릭
  2. 좌측 사이드바에서 [Pages] 클릭
  3. Branch 설정에서 main (또는 master) 브랜치와 / (root) 폴더 선택 후 [Save] 클릭
  4. 1~2분 뒤 https://[내아이디].github.io/[저장소이름]/ 상설 사이트 주소가 완성됩니다!

4 학생 영상 업로드 즉시 자동 재생 방식 2가지

방식 A. videos/ 폴더 자동 스캔 (가장 간편)

저장소에 videos/ 폴더를 만들고 영상 파일을 커밋하면, 사이트가 깃허브 API를 호출해 자동으로 영상을 찾아 재생 목록에 띄웁니다.

방식 B. videos.json 목록 파일 관리 (정석)

학생별 작품명, 작가명, 설명, 유튜브/비메오 링크까지 정교하게 표기하고 싶을 때는 videos.json을 수정하여 커밋합니다.

5 전시장 상설 태블릿 / 빔프로젝터 세팅 팁

  • 크롬 브라우저에서 사이트 접속 후 F11 또는 F를 누르면 주소창 없는 순수 갤러리 뷰로 전환됩니다.
  • OS 절전 모드 해제: 맥(화면 잠금 안 함 설정 또는 Amphetamine 앱), 윈도우(화면 및 절전 '안 함' 설정).
  • 브라우저 자동 오디오 차단 방지를 위해 사이트 첫 로드 시 [사운드 켜기] 버튼을 한 번 눌러주세요.
