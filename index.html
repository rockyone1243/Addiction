🚀 지속적 영상 업로드 & 전시 캡션 QR코드 시스템

영상이 완성될 때마다 바로 추가하는 3가지 방법

코딩 없이 영상을 즉시 추가하고, 관람객이 스마트폰으로 스캔할 수 있는 규격 명제표 QR코드를 바로 생성·인쇄하세요.

1

GitHub videos/ 폴더 업로드

새 영상이 완성되면 저장소의 videos/ 폴더에 파일만 올리세요. 사이트가 깃허브 API로 자동 감지하여 즉시 재생 목록에 반영합니다.

2

웹 UI로 직접 등록 (CMS)

상단 [영상 등록] 메뉴에서 제목, 작가명, 유튜브/비메오 링크를 입력하고 등록하면 즉시 사이트에 추가되며, 최신 videos.json 파일을 원클릭으로 내보낼 수 있습니다.

3

전시대 부착용 QR 캡션 명제표

상설 전시장 작품 옆 아크릴 거치대에 둘 수 있는 고해상도 QR코드와 캡션 명제표를 생성하여 바로 출력할 수 있습니다.

전시 QR 코드 및 명제표 생성기

스마트폰 스캔 시 404 Not Found 에러 원인 & 즉시 해결
⚠️ 예시 주소(404 원인)

스마트폰에서 404 에러가 뜨는 이유는 QR 코드에 예시 단어(your-username)가 포함되어 있기 때문입니다. 아래 칸에 본인의 실제 GitHub 아이디를 입력하시면 유효한 정상 접속 QR 코드로 즉시 자동 갱신됩니다!

내 깃허브 정보 입력 (원클릭 QR 생성 & 주소 검증)
새 탭 테스트
1
배포 소요 시간 (1~3분 대기): GitHub Pages를 활성화한 직후에는 깃허브가 서버를 빌드 중이므로 1~3분간 404가 뜹니다. 저장소의 Actions 탭에서 작업이 완료(초록 체크)될 때까지 잠시 기다려주세요.
2
저장소 Public(공개) 설정 필수: 무료 GitHub 계정은 Public 저장소에서만 웹 호스팅을 지원합니다. Private 저장소는 404 에러가 뜹니다. (Settings → General 맨 밑 Danger Zone에서 Change to public)
3
Settings → Pages 브랜치 저장 확인: 저장소 Settings → Pages에서 Branch가 main 및 /(root)로 설정되어 있고 [Save] 버튼이 눌렸는지 확인하세요.
4
파일명 소문자 index.html & 404.html: 파일명이 대문자(Index.html)이거나 하위 폴더에 있으면 안 됩니다. 배포 패키지에 포함된 404.html을 함께 올려두면 주소 입력 실수 시에도 메인으로 자동 연결됩니다.
